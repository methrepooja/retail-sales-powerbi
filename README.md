Retail Sales Power BI Dashboard

An interactive **Retail Sales Dashboard** built using **Power BI, DAX, and Power Query** to analyze sales performance, profitability, customers, and orders.

📊 Dashboard Preview

![Retail Sales Dashboard](retail_sale_dashboard.png)

🎯 Project Overview

This project analyzes retail sales data and presents important business metrics through an interactive Power BI dashboard.

The dashboard helps users understand:

* Revenue and profit performance
* Order and customer trends
* Monthly sales performance
* Product/category performance
* Overall business profitability

📌 Key KPIs

* **Total Revenue**
* **Total Orders**
* **Total Profit**
* **Profit Margin**
* **Total Customers**
* **Average Order Value**

📈 Dashboard Features

* Interactive KPI cards
* Sales and profit analysis
* Category-wise analysis
* Customer analysis
* Monthly trend analysis
* Interactive slicers and filters
* Dynamic Power BI visuals
* DAX-based calculations

🛠️ Tools & Technologies

* **Power BI**
* **DAX**
* **Power Query**
* **Microsoft Excel**
